# 推广素材包

## 一句话介绍

PromptCraft Studio 是一个开箱即用的提示词管理平台，把散落的提示词变成可搜索、可收藏、可复用、可部署的模板库。

## 小红书正文

很多人用 AI 的方式是：今天写一个提示词，明天复制昨天的聊天记录，后天又找不到最顺手的版本。

PromptCraft Studio 做的事情很简单：把常用提示词整理成模板，给它们加分类、标签和收藏，再用变量槽位快速生成最终提示词。

它适合：

- 小红书和公众号创作者
- 运营和客服团队
- 产品经理
- 独立开发者
- AI 工具重度用户

目前支持模板库、收藏、搜索、变量填充、质量评分、导入导出和静态部署。

## 公众号开头

提示词正在变成一种新的生产资料。

过去我们把提示词放在聊天记录、备忘录、飞书文档和表格里。真正高频使用时，这些提示词需要被管理、复用、评估和分享。PromptCraft Studio 就是围绕这个需求做的一个轻量工作台。

## 演示脚本

1. 打开首页，看模板库和统计数据。
2. 选择“小红书种草笔记”。
3. 填写产品名称、目标用户、核心卖点。
4. 展示生成结果并复制。
5. 收藏模板。
6. 新建一个自己的模板。
7. 导出 JSON，说明可以备份和分享。
