# Security Policy

## Supported Versions

The latest version on the default branch receives security fixes.

## Reporting a Vulnerability

Please report security issues privately to the maintainer before public disclosure.

Include:

- A short description
- Steps to reproduce
- Potential impact
- Suggested fix, when available

## Local Data

PromptCraft Studio stores prompt libraries in browser `localStorage` by default. Users should export backups before clearing browser data.

## Scope

Security-sensitive areas:

- Importing JSON prompt libraries
- Rendering user-authored template content
- Future backend adapters
- Future team-sharing features
